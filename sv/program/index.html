Våra program

WEINSE:s program

Vi skapar vägar till egenmakt

WEINSE utvecklar program som möter behoven hos kvinnor, organisationer och samhällen. Vårt arbete kombinerar personlig utveckling, yrkeskompetens, organisationsstöd och forskning för att skapa möjligheter till delaktighet, integration och hållbar utveckling.
